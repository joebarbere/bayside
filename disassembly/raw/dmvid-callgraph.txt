DMVID.EXE is the DeskMate video driver configuration utility.
It performs the following operations:

1. CRT startup (__astart -> __setenvp -> __setargv -> _main)
2. Parse command line for /AUTO switch
3. Locate DMCSR.CFG configuration file
4. Read current video driver setting from DMCSR.CFG
5. If /AUTO: auto-detect video adapter and update config
6. If interactive: display menu of video options (1-9)
7. Get user selection via keyboard input
8. Update DMCSR.CFG with selected video driver name
9. Display result message and exit

Configuration file: DMCSR.CFG
Config sections searched: [DMRESCFG], [DMCONFIG]
Config key: csr_config
Driver name format: DMVS<mode>.RES (e.g., DMVSVGA.RES)
