================================================================================
REVERSE ENGINEERING PRIORITY ANALYSIS
================================================================================

CRITICAL (needed for DESK.EXE shell to function):
  - DMVE*.RES / DMVS*.RES: Video drivers are essential for any display output.
    The DMVE files are small entry-point stubs (~5KB); the DMVS files contain
    the bulk of the video rendering code (22-26KB each).
  - DMFONT.RES: Font data and rendering, required for all text display.

HIGH (needed for core application functionality):
  - DMPLAY.RES: Sound playback engine (42KB, largest .RES). Needed for
    MUSIC.PDM and SOUND.PDM.
  - DMSSM.RES: Sound system manager. Companion to DMPLAY.
  - DMDBBLD.RES/DMDBRD.RES/DMDBUPD.RES: Database engine used by FILER.PDM.
  - DMFORM.RES/DMEFORM.RES: Form display engine, used by multiple apps.
  - DMPD*.RES/DMPE*.RES: Printer drivers, needed for TEXT.PDM print function.

MEDIUM:
  - SPELL.RES/SPL.RES: Spell checker for TEXT.PDM.
  - PROTOCOL.RES: Communication protocols for TELECOM.PDM.
  - ALARM.RES/ALRMINIT.RES: Alarm/scheduler support for CALENDAR.PDM.
  - DMEMM.RES: Extended memory manager (EMS/XMS).
  - PRGUF.RES: Program user functions framework.

LOW:
  - DMUNPACK.RES: Data decompression utility.
  - D87.RES: 8087 FPU emulation stub (818 bytes).
  - DICTARY.RES/DMTHES.RES/TRANSLAT.RES: Dictionary/thesaurus lookup stubs.
  - DMMD*.RES: MIDI driver variants (joystick port, parallel, serial).
  - AUTOLOAD.RES: Auto-load configuration helper.
